# MetalloLab

نسخه پایه و قابل ساخت اپلیکیشن آموزشی متالوگرافی.

## نکته مهم
پوشه Android عمداً در سورس اولیه قرار نگرفته است؛ GitHub Actions آن را با `flutter create` می‌سازد تا وابستگی به نسخه قدیمی Gradle/Android نداشته باشیم.

## ساخت APK
به Actions برو و workflow با نام **Build MetalloLab APK** را اجرا کن.
پس از موفقیت، از بخش Artifacts فایل **MetalloLab-APK** را دریافت کن.
